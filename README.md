# wohoef.github.io

Source of my blog: **https://wohoef.github.io**

Built with [Hugo](https://gohugo.io) and the [PaperMod](https://github.com/adityatelange/hugo-PaperMod) theme, and
published to GitHub Pages on every push to `main` (`.github/workflows/hugo.yaml`).

- New post: `hugo new content posts/<name>/index.md` (starts as a draft)
- Preview with drafts: `hugo server -D`, then open http://localhost:1313
- Publish: set `draft: false`, commit and push
